# Código de conduta

## O compromisso

Este projeto quer ser um lugar onde qualquer pessoa consiga contribuir sem ser
hostilizada — independente de experiência, idade, deficiência, etnia,
identidade ou expressão de gênero, nacionalidade, aparência, religião ou
orientação sexual.

## O que se espera

- **Critique o código, não a pessoa.** "Esse caminho quebra em Windows porque X"
  é revisão. "Você não sabe o que está fazendo" não é.
- **Traga evidência.** Este projeto se importa com medir em vez de deduzir, e
  isso vale também para desacordo: um caso que reproduz vale mais que uma
  opinião forte.
- **Aceite que a decisão pode não ser a sua.** Quem mantém decide o escopo. Um
  "não" para um PR é sobre a direção do projeto, não sobre você.
- **Presuma boa-fé.** Quase todo mal-entendido em texto é mal-entendido mesmo.

## O que não se aceita

- Assédio, em público ou em privado.
- Comentário depreciativo sobre qualquer das características acima.
- Linguagem ou imagem sexualizada.
- Publicar dado privado de outra pessoa sem autorização.
- Insistência em conversa que já foi pedida para parar.

## Alcance

Vale nos espaços do projeto — issues, pull requests, discussões, commits — e
quando alguém representa o projeto publicamente.

## Como relatar

Abra uma **[issue privada de segurança](https://github.com/hiperplano/aluy-mcp-rpa/security/advisories/new)**.
É o canal privado disponível no repositório, e serve também para isto: só os
mantenedores leem. Todo relato é tratado com discrição, e quem relata não sofre
retaliação.

Os mantenedores podem editar ou remover contribuições que violem este código, e
podem banir temporária ou permanentemente quem insistir.
